## ADDED Requirements

### Requirement: 關鍵字搜尋以字面比對
系統 SHALL 將後台訂單搜尋關鍵字 `q` 視為字面字串進行不分大小寫的部分比對，`%` 與 `_` MUST NOT 作為萬用字元。

#### Scenario: 搜尋底線
- **WHEN** 有兩張訂單，顧客名稱分別為 `王_小明` 與 `王大明`，搜尋 `q=_`
- **THEN** 只回傳 `王_小明` 的訂單

#### Scenario: 搜尋百分比符號
- **WHEN** 搜尋 `q=%`，且沒有任何欄位包含 `%`
- **THEN** 回傳 0 筆

#### Scenario: 空白關鍵字
- **WHEN** 搜尋 `q=%20%20`（只有空白）
- **THEN** 視為未指定關鍵字，回傳所有訂單
