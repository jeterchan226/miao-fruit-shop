# 訂單品項的下單價一經成立即固定，後台編輯不重新定價

訂單品項一經成立，它的下單價即固定；之後規格調價、後台編輯訂單其他內容，都不得以規格目前價格改寫既有訂單品項的下單價。後台仍可對訂單做完整的新增、修改、刪除（含代客下單、為既有訂單加訂），因為顧客臨時加訂很常見，要求重新下單或多付一次運費對顧客體驗不好。此決策推翻 2026-08 訂單編輯功能原本「編輯即以目前價格重算全部品項」的行為。

## Considered Options

- 編輯一律以規格目前價格重算全部品項（原行為）：只改地址也會改動顧客已同意的金額，否決。
- 後台不可新增或修改訂單品項、加訂須另行下單：違背「所有訂單統一在後台管理」的目的，且讓顧客多付運費，否決。
